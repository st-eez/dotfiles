## Beads Issue Tracker

This repo uses **bd (beads)** for durable work tracking. Full rules, creation rubric, and command reference auto-load via `bd prime` at session start on every engine (Claude: `.claude/settings.json` SessionStart + PreCompact hooks; Codex: `.codex/hooks.json`; pi: `beads-prime` extension). Run `bd prime` manually for a refresh.
